Option A — Docker Compose (recommended)

$docker compose -f docker-compose-lab.yml up --build
# Opens the lab guide at http://localhost:8080 automatically

Activate Redis profile
$mvn spring-boot:run -Dspring-boot.run.profiles=redis
# Or set SPRING_PROFILES_ACTIVE=redis in docker-compose-lab.yml (already done)
